# 指南

`ruststream-lapin` 是 [RustStream](https://powersemmi.github.io/ruststream/latest/zh/) 的 RabbitMQ Broker，基于 AMQP 0.9.1 客户端 [lapin](https://docs.rs/lapin) 构建。
这些指南带你把一个 RabbitMQ 服务从安装一路推进到生产环境。
从[快速开始](getting-started.md)读起。
