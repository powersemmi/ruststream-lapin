# Direct reply-to

Direct reply-to отправляет ответ прямо в канал запрашивающей стороны, без очереди ответов и не
более одного раза.

<Diagram name="replyTo" words={words} />

Запрашивающая сторона читает псевдоочередь `amq.rabbitmq.reply-to` в режиме без подтверждений.
Объявлять её не нужно. Запрос, опубликованный в том же канале со свойством `reply-to`, равным этому
имени, получает личный адрес: RabbitMQ заменяет значение свойства на `amq.rabbitmq.reply-to.` с
собственным суффиксом.

Запрос проходит как любое сообщение: через обменник в очередь и к потребителю. Отвечающая сторона
публикует ответ в обменник по умолчанию, используя полученный `reply-to` как ключ маршрутизации.
RabbitMQ передаёт ответ прямо в канал запрашивающей стороны. Никакая очередь его не хранит.

Ответ доставляется не более одного раза. Если канала запрашивающей стороны уже нет, ответ
отбрасывается, и запрос нужно отправить снова.

## В этом крейте

[`LapinRequester`](api:ruststream_lapin::LapinRequester) при первом запросе открывает собственный
канал, запускает в нём потребителя ответов и публикует в этом канале каждый запрос. Каждый запрос
содержит сгенерированный `correlation-id`, и ответ с тем же идентификатором завершает вызов. Ответы
читает одна задача на каждую запрашивающую сторону, на рантайме, на котором подключился брокер.
Ошибка канала закрывает канал, и ответы, которые ещё не пришли, теряются; следующий запрос
открывает новый канал. Запрос, ответ на который так и не пришёл, завершает тайм-аут этого запроса.

По умолчанию запросы непостоянные: запросу, которого после тайм-аута никто не ждёт, незачем
переживать перезапуск сервера.
[`LapinRequest::persistent`](api:ruststream_lapin::LapinRequest::persistent) включает постоянство.

Отвечающая сторона - обычный обработчик с ответом.
[`DirectReplyTo`](api:ruststream_lapin::DirectReplyTo), подключённый как преобразование его ответа,
отправляет каждый ответ по адресу, который назвал запрос, и повторяет его `correlation-id`. Ответ
приходит потребителю без подтверждений, поэтому его подтверждение ничего не делает.

Правила протокола задаёт RabbitMQ
([direct reply-to](https://www.rabbitmq.com/docs/direct-reply-to)).
